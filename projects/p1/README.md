跑通工具调用闭环

## 环境要求
1. Python 3.10
2. 其他包依赖见 requirements.txt



依赖安装方式
```
pip install -r requirements.txt
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple openai python-dotenv
pip install langchain-core langchain-openai langgraph python-dotenv -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 运行命令
```
python main.py
```
