## 3 三个 Agent 核心概念（定稿）

### 3.1 技能抽象与可组合架构

技能抽象：把散落在代码里的流程化能力（取数、计算、格式化输出等）封装成带标准输入输出协议、可独立注册复用的能力单元，即 Skill。可组合架构：Agent 按任务从技能库动态选择、串行或并行或条件分支地编排多个 Skill，多 Agent 经编排层协同，新能力随时以新 Skill 形式沉淀。

关键纠正：Skill 是能力单元（工具层），Agent 是决策主体（LLM 思考规划）——一个 Agent 内聚多个 Skill，多个 Agent 通过编排层协同，二者不是并列关系。编排落地靠三个机制：接口标准化（可插拔）、动态选择（按任务路由）、沉淀复用（持续注册）。四种编排模式：串行、并行、条件分支、循环重试。本项目 P3（投研多智能体）即为此概念的实战。

### 3.2 环境自主探索与上下文构建

环境自主探索：Agent 主动感知环境（可用工具、数据源、系统状态），减少对人工喂入信息的依赖。上下文构建：在多步任务执行中动态维护任务状态（当前进展、中间结果、约束条件），避免“失忆”。两者合起来就是：Agent 自己去环境里看，并在长任务中自己记。

### 3.3 迭代自我验证与纠错

指单次任务执行链内的「输出 → 自检 → 判定 → 纠错重试」闭环（Reflexion 反思模式）：输出结果后由校验器检查（规则校验、LLM 自评、工具结果比对），不通过则定位错误、修正重试，并设最大重试次数（如 3 次）防死循环。注意：这不是跨任务自我进化——当前 LLM 不具备自主持续学习能力。对应 A5 评估纠错，P1 的 max_turns 即是第一课。
